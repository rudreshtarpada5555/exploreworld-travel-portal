# ExploreWorld Travel Portal

Create a beautiful, modern and professional frontend-only Travel and Tourism Portal named "ExploreWorld".

IMPORTANT: This project is only a frontend prototype for a college End Semester Examination. Do not create any backend, database, API integration, authentication system or payment gateway. Use HTML, CSS, JavaScript and React as appropriate.

DESIGN:
- Premium and professional tourism website.
- White, sky blue and dark navy color combination.
- Beautiful travel destination photographs.
- Modern cards with rounded corners and subtle shadows.
- Smooth hover effects and simple animations.
- Attractive typography and clean spacing.
- Fully responsive on desktop, tablet and mobile.

CREATE THE FOLLOWING PAGES:

1. HOME PAGE
- Modern navigation bar with ExploreWorld logo.
- Home, Destinations, Packages, Hotels, About and Contact links.
- Large hero section with beautiful travel background image.
- Heading: "Explore the World, Create Memories".
- Subtitle describing the tourism portal.
- Destination search bar.
- Explore Destinations button.
- Popular destinations section.
- Featured travel packages.
- Why Choose Us section.
- Customer testimonials.
- Professional footer.

2. DESTINATIONS PAGE
- Display popular Indian tourist destinations.
- Include Goa, Kashmir, Manali, Jaipur, Kerala, Gujarat, Mumbai and Agra.
- Use beautiful destination images.
- Add destination names, short descriptions and Explore More buttons.
- Add working search and category filters.

3. PACKAGES PAGE
- Display attractive travel package cards.
- Show destination, package image, number of days, estimated price and facilities.
- Include View Details and Book Now buttons.
- Add filters for budget and travel category.

4. HOTELS PAGE
- Display sample hotels in popular tourist destinations.
- Show hotel images, names, locations, facilities and estimated prices.
- Add View Details buttons.

5. BOOKING PAGE
- Create a modern travel booking form.
- Fields: Full Name, Email, Phone, Destination, Travel Date, Number of Travellers and Package.
- Add a Submit Booking button.
- Use frontend-only form validation.
- Show a demo booking confirmation message after submission.
- Do not save information to any database.

6. BUDGET CALCULATOR PAGE
- Let users select a destination.
- Enter number of travellers and travel days.
- Calculate estimated hotel, food, transport and miscellaneous expenses.
- Display total estimated cost and per-person cost.
- Use sample prices and frontend JavaScript calculations.

7. ABOUT PAGE
- Introduction to ExploreWorld.
- Mission and vision.
- Our services.
- Why travellers should choose us.

8. CONTACT PAGE
- Contact form with name, email, subject and message.
- Display sample contact details.
- Show a demo success message after form submission.

FUNCTIONAL REQUIREMENTS:
- Navigation between all pages must work.
- Search and filters must work using sample data.
- Buttons should perform their intended frontend actions.
- Forms must validate user inputs.
- Budget calculator must calculate correctly.
- Use React state and sample JavaScript data.
- Add suitable success messages and error messages.
- Do not use fake live booking or payment features.

FINAL REQUIREMENTS:
- Make the entire application frontend-only.
- Keep all pages consistent in design.
- Ensure all buttons and interactions work.
- Make it responsive for mobile and desktop.
- Use attractive images and professional layouts.
- Make it suitable for a college ESE project demonstration.

Generate the complete working frontend prototype.
